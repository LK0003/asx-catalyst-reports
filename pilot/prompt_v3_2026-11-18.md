EVIDENCE RULES (apply to every label in the report):

- CONTENT = 'read' only if IN THIS RUN you obtained the text of the announcement document (or an identified mirror/company page) from a URL you name, and you state at least one specific fact or figure taken from that text. Otherwise write 'headline only' or 'not accessed'.
- Earlier reports in this repo are NEVER evidence for LISTING or CONTENT. If you rely on an earlier report, label it 'carried forward from <filename>, not re-verified this run'. You may use earlier reports only to decide whether something was already covered.
- FACT vs INTERPRETATION vs SPECULATION must stay visibly separate. Never invent a ticker, figure, time or consensus estimate; write 'Not verified' instead.
- NEVER write 'no ASX announcement today' or similar. The only permitted wording is: 'No matching announcement found in the retrieved listing (N rows retrieved, first time - last time)'. This does NOT prove there is no relevant news or no earlier announcement, and the report must not imply it does. Keep 'sources worked, nothing found' separate from 'sources inaccessible'.
